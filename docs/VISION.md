# PocketPad ビジョン

> **Project Pocket は人とAIと端末をつなぐ基盤であり、**
> **PocketPad はその基盤によって、日々の小さな行動を世界と図鑑に変える最初のプロダクトである。**

この文書は**変えないもの**だけを書く。実現方法は書かない。

| **VISION.md**（この文書） | なぜ存在するか。世界観と原理原則 | ほぼ固定 |

「絶対に変更しないもの」と「現時点の実現方法」を同じ文書で育てると、いずれ両方が曖昧になる。だから分けてある。

## 0. コア（絶対に変えない）

### ミッション

ユーザーが「今日もいい一日だった」と思える世界を作る。

### 原理原則

世界観よりも価値観を守る。

**変えないもの:**

- 人は日々の積み重ねで成長する
- 良い行動は世界を豊かにする
- 小さな一歩に価値がある
- AIは評価者ではなく伴走者

**この4つは今後も絶対に変更しない。**

> **「良い行動」は生産性ではない。** その人が大切にした小さな一歩のこと。
> PC操作の量やコミット数を「良い行動」と定義した時点で、この原則は死ぬ。

---

## 1. 世界の始まり

全員同じ場所から始まる。**「天国」**。

ここは宗教を説明する場所ではない。安心して人生を始める場所。
AIが優しく迎えてくれる。

そこから、ユーザー自身の人生が始まる。

## 2. 世界はAIが育てる

世界は最初から完成していない。ユーザーの行動によってAIが世界を生成する。

| 行動 | 生まれるもの |
|---|---|
| 家族との時間が多い | 家庭 |
| 勉強を続ける | 学校 |
| プログラムを書く | 研究所 |
| 音楽活動をする | ライブハウス |
| 運動する | ジムや公園 |

つまり **世界＝人生そのもの** になる。

## 3. AIの役割

AIは毎日、ユーザーの行動を見て、世界を少しだけ変化させる。

背景 / 建物 / 植物 / 動物 / NPC / 天気 / 季節感 / キャラクター / コメント。

これらを毎日生成する。毎日少し違う。だから毎日開きたくなる。

## 4. 図鑑

図鑑はコレクションではない。**人生の記録**である。

| 今日したこと | カードになるもの |
|---|---|
| 人を助けた | 優しい旅人 |
| 集中して開発した | 静かな研究者 |
| 家族と過ごした | あたたかい父 |

つまり今日の自分が一枚のカードになる。人生が図鑑になる。

## 5. 人生の場所

「部屋」という概念ではなく **「人生の場所」**。

家庭 / 学校 / 工房 / 図書館 / 研究所 / 音楽ホール / 農園 / 公園 / 海 / 山 / 星空 / 神殿。

必要になった時だけ、自然に追加される。

## 6. UIの芯

**情報量を減らす。最初に見せるものは1つだけ。**

```
今日やること → 行動 → 世界が変わる → 図鑑が更新される
```

この流れだけで十分。

## 7. AIに任せる範囲

| AIが自由にしていい | AIが変更してはいけない |
|---|---|
| キャラクター生成 / 世界生成 / 背景 / コメント / 建物 / NPC / 演出 | 世界のルール / コア思想 / 原理原則 / UIの基本導線 |

---

## 判断に迷ったら

新しい機能を足すときは、必ずこれを訊く。

> この機能は、**ユーザーが人生の積み重ねに意味を感じられるようになるか？**
>
> YES → 採用。**NO → 作らない。**

そして §0 の4行を読み直す。**世界観は変えていい。価値観は変えない。**

---

## PocketPadが目指す姿

毎日の行動が世界になり、世界が思い出になり、思い出が人生になる。

これがPocketPadの核である。

> **人が考える。AIが支える。Codexが作る。Pocketがすべてをつなぐ。**
